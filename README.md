🌐 Translator Creator

✨ Your multilingual voice assistant — translate, speak, and listen in seconds!

🎯 About the App

Translator Creator is a smart Streamlit-powered web app that lets you translate text into multiple languages, hear it in natural AI voices, and even download the audio — all wrapped in a beautiful, responsive UI.

LIVE VIEW:https://translator-311madewithpassion.streamlit.app/


🧠 Built using:
Python · Streamlit · Googletrans · Edge-TTS · gTTS · Formspree · Lottie Animations

✨ Features

✅ Translate text instantly across 6+ languages
🎧 Listen to translations in AI voices (male/female)
💾 Download translations as MP3 files
🌗 Light & Dark mode themes
📱 Fully responsive for mobile and desktop
📬 Built-in feedback form with Formspree
💡 Clean, aesthetic design with Lottie animations

User Flow

🏠 Home: Learn what the app does
🌍 Translate Languages: Translate + listen + download
🎙️ Voice Styles: Hear English text in multiple voices
👨‍💻 About Creator: Know the developer
📬 Contact/Feedback: Send feedback via form

Tech Stack

Category	Tools Used
Frontend	Streamlit, CSS, Lottie Animations
Translation	Googletrans
Text-to-Speech	Edge-TTS, gTTS
Feedback Form	Formspree API
Media Handling	Base64, Tempfile
